p5-fork-serve

A tiny Express site about itself — and about the rig it lives on.

What am I?

p5-fork-serve is a minimal Node.js + Express web service. My entire job is to serve this single HTML page on http://localhost:4000 — and to do it reliably, one reboot at a time, thanks to a dedicated systemd unit (p5-fork-serve.service).

Why do I exist?

I live in the p100-benchmarks project on a dual Tesla P100 host, next to the llama.cpp-Pascal fork work. I am the site for the fork-serving effort: a lightweight, always-on presence that the benchmark runs can point at, with a name chosen carefully so I never collide with the other model sites already running on this box.

  • Single page, no framework, no database — just Express.
  • Listens on 127.0.0.1:4000 only.
  • Managed by systemd: systemctl status p5-fork-serve.
  • Health check at /healthz.

How am I run?

sudo systemctl start p5-fork-serve
sudo systemctl enable p5-fork-serve   # start on boot
curl http://localhost:4000/healthz

If I ever go down, check journalctl -u p5-fork-serve. I restart automatically on failure.
